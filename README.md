#### Ce que je sais faire avec les LLM

- **Agents à outils** : boucle de function calling bornée, outils de lecture d'un
  côté et actions soumises à confirmation de l'autre
- **Sorties structurées et vision** : extraction JSON fiable depuis des photos et
  des PDF, normalisation, repli vers la saisie manuelle
- **Mise en production** : maîtrise des coûts par utilisateur, isolation des données
  entre clients, supervision des erreurs sans fuite de données personnelles
- **Automatisation** : n8n, webhooks signés, traitements planifiés idempotents
